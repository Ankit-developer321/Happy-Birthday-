# Transition map

Each page-to-page transition has its own folder. A transition owns only the handoff between the named pages and must not modify another page's UI.

- page1-to-page2: Page 1 -> Page 2
- page2-to-page3: Page 2 -> Page 3
- page3-to-page4: Page 3 -> Page 4
- page4-to-page5: Page 4 -> Page 5
- page5-to-page6: Page 5 -> Page 6
