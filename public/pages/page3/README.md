# Happy Birthday ❤️

A mobile-first, cinematic birthday surprise website.

## Edit it

Open `public/script.js` and edit the `birthday` object at the top. You can change the name, messages, memory captions, little-things cards, and final reveal.

Optional assets go in `public/assets/`:
- `birthday-song.mp3`
- `memory-1.jpg` … `memory-4.jpg`

## Run locally

Because this is a zero-build static site, open `public/index.html` through any static server. It can also be served directly by a static host.

## Deploy on Render

Create a Render Static Site using this repository. Set **Publish Directory** to `public` and leave the build command empty.

The site has no backend, database, login, or API keys.
