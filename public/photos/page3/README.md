# Page 3 Memory Photos

Save the Page 3 photos in this folder using these exact names:

- `1.jpg` — Memory 1
- `2.jpg` — Memory 2
- `3.jpg` — Memory 3
- `4.jpg` — Memory 4

You can replace any photo later without changing the Page 3 design/code, as long as the filename stays the same.

Supported image formats can be added if the Page 3 mapping is updated accordingly.
