# Birthday assets

Add these optional files here:

- `birthday-song.mp3` — local birthday/background music. It starts only after the visitor taps the opening button because browsers block unsolicited autoplay.
- `memory-1.jpg` through `memory-4.jpg` — your photos. The current cards are polished placeholders; photos can be wired in next.

Keep personal photos/music in this folder. No external copyrighted music URL is used by the site.
